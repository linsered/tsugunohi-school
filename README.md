# 放学后 · 逢魔之时

> 一条走廊，一个键，五天。

一款横向卷轴的心理恐怖小品。你只需要按住 **←** 一直向左走。五天里反复走同一条走廊，
擦肩而过的人一天比一天不对劲——直到最后一天，走廊上全是他们。

## 在线游玩

**https://linsered.github.io/tsugunohi-school/**

打开即用，无需安装。建议戴耳机、全屏，并保持按住 **←**。

---

## 玩法

| 操作 | 功能 |
|---|---|
| **←** / **A** | 向左走（唯一必需按键） |
| **↑ ↓ / W S** | 菜单选择 |
| **Enter / Space** | 确认 |
| **Esc** | 返回 |

菜单里的选项也能直接用鼠标点击。

**松开方向键就会停下。** 停下本身是有代价的。

## 故事

学校里有学生因为霸凌死在了这栋楼里。黄昏——逢魔之时——他们回来，无差别地诅咒还活着的人。

季靛休学了一个学期，今天回来拿东西。雪子是她唯一的朋友。
第一天她们在走廊里打了个招呼，约好一起走。

第五天，雪子从对面走过来。低着头。头发把脸全盖住了。

## 三个结局

判定条件互斥，按优先级从高到低。全部可复现，可用 `--verify` 秒级回归。

| 结局 | 触发条件 |
|---|---|
| **留 下** | 第五日，在走廊尽头（镜面区）停留 ≥ 2.6 秒 |
| **闭 眼** | 连续静止 ≥ 15 秒（走动一步即清零） |
| **放 学** | 走完五天，以上都没有发生 |

结局收录持久化到 `user://ending.cfg`。未解锁的条目只显示 `？？？`，不剧透触发方式。

## 技术实现

### 分层场景，而不是一张背景图

走廊由若干独立图层叠出来，这样才能做「物件消失 / 物件变成鬼 / 窗外有东西经过」：

```
背景墙（正 + 镜像交替平铺，无缝）
  ├─ 窗外鬼影（画在窗框之前 → 读作玻璃外面）
  ├─ 门窗构件（独立贴图，按世界坐标周期排布）
  ├─ 走廊物件（纸箱 / 拖把桶 / 椅子 / 灭火器 / 鞋）
  │    └─ 第三日起部分物件替换成「物件鬼」
  └─ 压暗 / 应急红灯 / 积水
```

所有构件都挂在**世界坐标**上跟着背景滚，不跟镜头。主角往前走时背景向右移，
视觉上才是主角在向左走。

### 卡司

- **9 个行人**：不同校服、发型、体型的男女学生，外加老师、女老师、门卫
- **9 个对应的鬼形态**：学生鬼按人位一一对应；教师与门卫的鬼单独制作
- **4 种极端变异鬼**：折颈 180°、超长颈、巨颅、五官旋转 90°
- **2 张角落鬼**：随机从画面左侧或右侧冒出

**腐化不可逆**：每个行人位有独立状态位，一旦变成鬼，后面所有天都是鬼，绝不回退。

### 行人与进度挂钩

行人不是按秒表刷新的，而是**按主角前进的距离**推进。站着不动不会消耗当天的行人名额——
否则玩家在走廊里站一会儿，再走就会发现整条走廊空了。

### 全屏跳脸

7 张池子，洗牌后一局内不重复；池子空了就不触发，宁可少吓一次也不重播。
瞬间占满全屏，固定保持 0.52 秒后直接切掉，不做淡入、不做位移。

## 美术管线

角色与场景素材为 AI 生成 + 程序化处理：

1. **一律绿幕生成** —— 白底图上白色校服与背景同色，任何颜色键都会把衣服一起吃掉
2. **严格绿键**：只键「G 通道明显高于 R/B，且与画面边界连通」的像素
3. **边界连通判定**：内部区域一律保留，避免衣服被挖出洞
4. **削边 + 内侧压暗**：原图自带的高光轮廓在暗场里会变成惨白光晕，需往里削 2px 再压暗 4px 宽的一圈
5. 全部音效为 `numpy` 程序化合成，无第三方素材

> 角色设计刻意保持「人偶感」：**主角的脸是一块空白**，鬼的脸被头发整块盖住。
> 一旦做得像真人，就会掉进 cosplay 的廉价感里，恐怖谷反而失效。

## 自检与回归

项目内置两个可复现的验收入口，改动后不用靠肉眼：

```bash
# 结局判定表 + 行人队列断言，约 10 秒
./engine/godot.exe --path . -- --verify

# 全流程截图（菜单 / 图鉴 / 五天 / 闭眼 / 跳脸 / 结局），约 5 分钟
./engine/godot.exe --path . -- --shots
```

`--verify` 输出示例：

```
[verify] mirror=0.0 still=0.0  -> normal (want normal) OK
[verify] mirror=2.6 still=0.0  -> taken  (want taken)  OK
[verify] mirror=0.0 still=15.0 -> blink  (want blink)  OK
[verify] mirror=9.0 still=20.0 -> taken  (want taken)  OK   ← 优先级覆盖
[verify] mirror=0.0 still=14.9 -> normal (want normal) OK   ← 边界不误触
[crowd] day1 size=8 uniq=8 human=true  ghost=false OK
[crowd] day5 size=8 uniq=8 human=false ghost=true  OK
[crowd] monotonic OK
[crowd] idle_spawn=0 walk_spawn=8 OK
```

## 构建与部署

Web 构建由 Godot 4.7.2 + Web 导出模板生成，导出预设见 `export_presets.cfg`，
输出目录为 `build/web/`。站点从 `main` 分支的 `/docs` 目录经 GitHub Pages 部署：

```bash
# 1. 导出 Web（需安装对应版本的导出模板）
godot --headless --path . --export-release "Web"

# 2. 复制到 Pages 目录并提交
cp -r ../build/web/. docs/
git add docs && git commit -m "更新 Web 构建" && git push
```

推送后 GitHub Pages 自动重建，约 30 秒后站点更新。本仓库已开启 Pages（legacy 流程，
HTTPS 强制）。也可用 `--verify` / `--autoplay` 做本地回归后再导出。

## 已知限制

- **人物与门的比例不成立**。平视侧立面 + 上半身特写这两个要求在几何上互相矛盾：
  人物是前景贴片，门在中景，没有透视兜底。彻底解决需要改成背后跟随的透视镜头。
- **Web 版加载体积约 51MB**（wasm 38MB + pck 13MB），首次打开需等待浏览器下载与编译，
  之后会走缓存。低配设备帧率可能下降。
- 退出时偶发 `1 resources still in use`，属 tween 持有贴图引用的良性告警，不影响游玩。
