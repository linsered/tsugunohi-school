# 「翌日」系列全解构 · 与《翌日 · 课后》设计案

> 本文件分两部分：**第一部分**拆解 ImCyan《翌日》（つぐのひ / Tsugunohi）全系列的机制、结构、美术与声音；
> **第二部分**是我们据此制作的同风格原创短篇《翌日 · 课后》的完整设计案与实现说明。

---

## 2. 类型定位：日常侵蚀系（日常侵蝕ホラー）

它不属于"关卡制恐怖"（生化、逃生），也不属于"叙事恐怖"（层层恐惧）。它是**"日常的逐日变质"**：

- 场景是日本人每天真的会走的路：通学路、商店街、校舍走廊、私铁车厢、老式公寓。
- 恐怖不来自"设计出来的怪物"，而来自**"这里昨天不是这样的"**。
- 玩家不是受害者扮演者，更像**目击者**——你无法反抗，只能看着它变。

这个定位决定了后面所有的设计取舍。

---

## 3. 玩法解构：一个键

| 项 | 设定 | 设计意图 |
|---|---|---|
| 输入 | 只有 **←** | 把操作成本压到 0，注意力全部让给画面和声音 |
| 移动 | 固定速度、偏慢（观感 1.2–1.5 m/s） | 慢 = 你有时间看清每一个不对劲 |
| 能力 | 不能跑、不能回头、不能攻击、不能交互、不能用道具 | 剥夺能动性 = 剥夺安全感 |
| UI | 几乎没有。没有血条、物品栏、任务提示 | 一旦有 HUD，玩家就进入"攻略"心态，恐惧消失 |
| 唯一界面 | 「第 N 日」日期卡 | 唯一的进度反馈，也是唯一的倒计时 |
| 单篇时长 | 10–40 分钟 | 短，是为了让"重复"还不至于变成枯燥 |

**关键机制：停下来是有代价的。**

表面上看，停下来只是"暂停剧情推进"。但在多个篇章里，**停下 / 回头 / 搭话**是坏结局的触发条件：

- 第一话：中途多次停下观察路边人影 → 道路无限轮回，被黑影吞噬。
- 第二话：忍不住回头看向路口镜子 → 红衣女鬼冲出，被困镜面世界；全程不回头 → 女鬼扑空，哥哥穿女装引走怨灵的**搞笑隐藏结局**。
- 第三话：遇见警察时停下交谈 → 父亲的秘密暴露，主角被软禁；埋头赶路不搭话 → 警察上门逮捕父亲，主角重获自由。
- 第四话：望向窗外看到平行列车里的自己 → 意识到自己早已死亡，坠入黑暗。

**这就是系列的灵魂**：它把"凝视"这个动作，做成了唯一的道德选择。你看得越多，越出不去。

## 4. 结构解构：时间即关卡

```
第 1 天 ████░░░░░░  常态，只有一点点违和
第 2 天 ██████░░░░  细节变了，但没人提起
第 3 天 ████████░░  规则开始失效
第 4 天 ██████████  实体出现，且不止一个
第 5 天 ███████████ 崩坏 + 爆发 + 结局
```

三个可复用的结构特征：

**(1) 场景复用率极高。** 五天走的是同一条路，同一批贴图、同一段 BGM。成本极低，效果极强——因为**熟悉感是违和感的分母**。玩家越认得这条路，第 5 天的一个错位就越致命。

**(2) 每天只加 3–5 个变化。** 增量清单通常分布在这三层：

| 层 | 变化内容 |
|---|---|
| 环境 | 天气、光照、门窗开合、招牌、行人数量、地面污渍、墙面涂鸦 |
| 声音 | 脚步声回声、环境音突然消失、多出一层低频、远处多一个声音源 |
| 主体 | 主角的衣服、影子、步态、表情、呼吸声 |

一次只动一两个，玩家会怀疑自己记错——**这个"怀疑自己"的瞬间，就是恐怖的最高点**。

**(3) 重复本身就是恐怖源。** 不是"jump scare 的间隔"，而是"我知道我走过这里，但这里不对了"。所以系列里最有效的时刻，往往没有任何音效，只是背景里多站了一个人。

## 5. 美术解构

**核心矛盾：看起来假，又看起来真。**

- **场景**：几乎 1:1 还原日本日常场所。构图刻意平庸——没有英雄机位，没有引导线，就是"随手拍的一张照片"。
- **人物**：早期是低模 3D 角色贴在实拍底图上，两者质感不匹配。这个"不匹配"反而成了系列最恐怖的视觉特征：**她不属于这个画面**。
- **调色**：青灰 / 暗绿为底，暗部压死（几乎纯黑），高光很少。唯一的暖色是钠灯的橙和血的暗红。
- **分辨率**：低。贴图糊、边缘软。糊 = 记录片 = 可信。
- **机位**：固定侧视 / 背面跟随，人物占画面高度约 1/3–1/2。永远看得见"前面还有多长"。
- **恐怖实体**：几乎清一色是**人形 + 长发 + 静止**。不设计怪物造型，靠**"不该出现的位置"**生效——走廊尽头、教室门内、列车窗外、镜子里。
- **后期**：颗粒、暗角、轻微色差、偶发扫描线。

**一条反直觉原则：画面越"普通"，异常越刺眼。**
所以千万不要用哥特、血腥、高对比的"恐怖美术"。血和断肢会让人兴奋，普通走廊里多出一个人会让人**后背发凉**。

---

## 6. 声音解构

系列音频预算极低，但结构非常清楚，永远是三条轨：

| 轨 | 内容 | 作用 |
|---|---|---|
| 底噪 drone | 40–60 Hz 正弦 + 滤波噪声，缓慢 LFO | 持续压迫；随天数变厚、变低 |
| 脚步 | 4 个随机变体，轻微音高抖动 | **节拍器**。它给玩家"时间在走"的体感 |
| 事件音 | 门吱呀、水滴、椅子拖动、远处铃声 | 定位"异常在哪里" |

几条实战规律：

- **脚步声一变，恐惧立刻成立**：多出一双、出现回声、突然消失，三种都极其有效，成本几乎为零。
- **童谣 / 音乐盒**是日本恐怖的通用语汇：反放、失谐（detune ±0.2%）、变速。
- **跳跃惊吓的配方**：宽频噪声爆 + 低频下坠（120→35 Hz）+ 短促高频啸叫，总长 0.3–0.6 秒。超过 1 秒就变成"音效展示"，不再是惊吓。
- **静音是最强的音效**：爆发前 2 秒抽掉所有环境音，观众的耳朵会自己"竖起"。

---

## 7. 可复用公式（我们据此做的七条铁律）

1. **一个键**。多一个键就多一分"游戏感"，少一分"目击感"。
2. **同一条路，走五天**。复用是资产，不是偷懒。
3. **每天只加 3–5 个变化**，且跨层（环境 / 声音 / 主体）各加一点。
4. **声音先变，画面后变**。耳朵比眼睛先察觉不对。
5. **实体永远是人形**。不设计怪物，只设计"位置"。
6. **恐怖来自错位，不来自造型**。
7. **结局由"你是否停下来"决定**。把凝视变成代价。

# 第二部分　《翌日 · 课后》设计案

## 8. 一句话

> 一个休学归来的高二女生，在放学后的走廊里走了五天。
> 她只需要一直向左走。**只要不停下来，就能走出去。**

## 9. 设定

- **主角**：佐仓 澪（Sakura Mio），高二，因病休学一学期，今天是复课第一天。
- **场所**：私立樱丘高中，三层教学楼西侧走廊——从楼梯口到鞋柜，正常步行 3 分钟。
- **异常核心**：走廊里多了一个"她"。不是鬼，是**没能走出去的那个她**。
- **主题**：不是"鬼来了"，而是"**你还没离开**"。

## 10. 五日结构

| 日 | 标题 | 环境变化 | 声音变化 | 主体变化 |
|---|---|---|---|---|
| 一 | 帰り道 | 一切正常，只是没有声音 | 只有脚步和远处社团 | —— |
| 二 | 誰かいる | 教室门半开；墙上多了一张被划掉脸的集体照 | 多一层极低频；远处门响 | 走廊尽头有人站着，走近就没了 |
| 三 | 同じ教室 | 所有门全开，门后是**同一间教室**；时钟倒转 | 铃声在错的时刻响 | 每间教室黑板上都是她的名字 |
| 四 | 増える | 门框阴影里开始站人，一个变两个变三个 | 脚步声多了一双 | 镜子/玻璃里出现延迟的自己 |
| 五 | 翌日 | 灯全灭，只剩应急红灯；地面有积水 | 心跳；环境音全部消失 | 鞋柜里全是她自己的鞋 |

**事件密度**：每天 7–9 个触发点，其中只有 1–2 个是"硬惊吓"，其余全是**环境级的细微异变**。这个比例是刻意模仿原作的——大部分时间你只是"觉得不对"，而不是"被吓"。

## 11. 机制（与系列一致）

- **唯一操作**：按住 **←**（或 A）向左走。松开即停。
- **无战斗、无道具、无解谜、无对话选项。**
- **凝视代价**：累计静止超过 30 秒，或第五日在镜面区停下超过 2.2 秒 → **坏结局**。
- **两个结局**：
  - **坏结局「留级」**——你回头了。所以明天，也还在。
  - **真结局「翌日」**——你没有回头。第二天，走廊是空的。

字幕极简，全篇不到 20 句，且都是主角的内心独白——**不解释、不点破、不总结**。

## 12. 美术规格

| 项 | 规格 |
|---|---|
| 基准分辨率 | 640×360（整数倍放大到 1280×720 / 1920×1080） |
| 视角 | 固定侧视，人物固定停在屏幕 x=268（偏左，给"前方"留空间） |
| 色板 | 青灰 #3D4A52 / #2B3438、暗部 #0A0D0F、荧光灯惨绿 #8FB89C、应急红 #A0443C |
| 走廊 | 程序化绘制：320px 一格，格内为「门 / 窗 / 告示板 / 鞋柜」四种，任意长度无缝 |
| 人物 | 152px 高（≈ 画面高度 42%），三帧循环（站立 / 步幅 A / 步幅 B）+ 1px 上下起伏 |
| 后期 | 颗粒 5.5%、暗角 38%、色差 0.0022、扫描线 16%（可在 shader 里关） |

## 13. 声音规格

全部由 numpy 程序化合成，**零版权依赖**：

| 文件 | 合成方式 | 用途 |
|---|---|---|
| amb_day / dusk / night / void | 多谐波正弦堆叠 + FFT 低通噪声 + 呼吸 LFO，24–26 s | 每日底噪，逐日变低变厚 |
| step1–4 | 低通噪声 + 70→58 Hz 闷响 + 高频点击，22 ms 衰减 | 脚步，随机取一 + 音高抖动 |
| bell | 威斯敏斯特钟声前四音，五重泛音 + 指数衰减 | 放学铃，用在"错的时刻" |
| musicbox | 小调 16 音，失谐 ±0.16%，磁带抖动 | 记忆/童年，反用 |
| stinger | 噪声爆 + 120→35 Hz 下坠 + 2.4k→900 Hz 啸叫 | 跳跃惊吓，1.8 s 内衰完 |
| whisper | 带通噪声 + 3.4/1.7 Hz 双共振峰调制 | 耳语 |
| heartbeat / door / drip / scrape / hum | 单音 + 包络 / 摩擦噪声 | 定位异常 |

## 14. 技术实现

```
tsugunohi_school/
├── project.godot              # Godot 4.7, GL Compatibility, 640×360 canvas_items
├── scenes/Main.tscn           # 只有一个根节点，场景树在运行时构建（便于移植）
├── scripts/
│   ├── game.gd                # 状态机 / 日程 / 事件导演 / 音频 / UI
│   └── corridor.gd            # 走廊程序化绘制 + 加法混合灯层
├── shaders/grade.gdshader     # 颗粒 / 暗角 / 色差 / 扫描线
├── assets/
│   ├── art/                   # Agnes 生成 + 抠图 + 规范化
│   ├── audio/                 # numpy 合成
│   └── fonts/                 # 微软雅黑 + 宋体（标题用宋体，接近明朝体）
└── tools/build_assets.py      # 素材管线：抠图 → 分级 → 归一化 → 合成音频
```

**渲染分层**

```
CanvasLayer(10)  UI  ── 字 / 暗场 / 日期卡 / 惊吓特写
    └ grade.gdshader（采样 SCREEN_TEXTURE，只作用于 2D 世界，不吃 UI）
2D 世界
    ├ LightLayer  (BLEND_MODE_ADD)  灯管 + 光晕 + 地面反光
    ├ corridor    (普通混合)        天花 / 墙 / 墙裙 / 门 / 窗 / 地面 / 压暗
    ├ ghost  ghost_far
    ├ sprite  (玩家)
    └ shadow
```

**素材管线（`tools/build_assets.py`）**

1. **取底**：从四角采样估计背景色（不假设纯洋红，兼容偏品红的底色）。
2. **抠像**：按到背景色的欧氏距离生成 alpha，再做 **over 反混合** `fg = (obs − bg·(1−α))/α`——比"抠掉背景"多一步，能把边缘的洋红反光彻底还原，不留粉边。
3. **除影**：AI 偶尔会在脚下画投影。先取"与头顶连通的主连通域"，再按"背景色相 + 暗部 + 位于脚部区域"二次剔除。
4. **归一化**：按上半身 alpha 重心水平对齐（不是 bbox 中心），避免步幅帧左右抖动；脚底统一对齐画布底部。
5. **分级**：降饱和 18%、轻微压暗、冷色偏移，让人物融进走廊的青灰色调。

> 三帧取自**同一张精灵表**（一次生成、横向排三帧），这是保证服装、比例、光照一致的关键——分开生成一定会出现袜子颜色、身高的漂移。

## 16. 后续可以加什么

- **第二话**：把场景换成"放学后的巴士站"，机制换成"只在雨停的间隙能走"。
- **多语言**：字幕表抽出到 JSON，加日/英文本。
- **成就式隐藏分支**：第三日全程不眨眼（不松手）会看到教室里多一张自己的桌子。
- **移动端**：单指长按即走，天然适配。
